01 / KHỞI ĐỘNG

HƯỚNG DẪN CHẠY DALTUI TRÊN OBC

MỞ DALTUI TRÊN OBC

Trên terminal OBC, chạy bằng tài khoản root. FSW tạo các socket khi service khởi động:

systemctl start dal_obc_fsw

Mở DALTUI qua console socket:

TERM=xterm-256color /home/root/tools/bin/daltui --console /run/dal/dal_obc_fsw/console.sock --poll

Hoặc mở qua RS-422 socket:

TERM=xterm-256color /home/root/tools/bin/daltui --rs422 /run/dal/dal_obc_fsw/rs422.sock --poll

Chọn một trong hai lệnh mở DALTUI. Đây là các đường dẫn mặc định; dùng đường dẫn đã cấu hình nếu FSW có override. RS-422 socket là socket cục bộ của FSW, không phải cổng serial /dev/ttyS1. Hai lệnh trên dùng --poll để đọc housekeeping định kỳ. Thay --poll bằng --manual nếu chỉ muốn UPDATE theo yêu cầu; bỏ tùy chọn này để chạy control-only. Dùng đường dẫn đầy đủ vì thư mục /home/root/tools/bin có thể không nằm trong PATH. Thoát bằng phím q.

KEYBOARD

CONTROL · TRÌNH TỰ THAO TÁC
  1. Tab / [ ] hoặc 1–6: chuyển HOME, OBC, EXP, PDU, LOG, CFG.
  2. , / .: đổi subtab. < / >: đổi cột Control; ở mép có thể chuyển sang subtab kế bên.
  3. ↑ / ↓ hoặc k / j: chọn dòng. Enter: mở EDIT/SELECT hoặc chạy RUN.
  4. Trong hộp EDIT, nhập số rồi Enter để lưu draft; Esc hủy. Trong SELECT, chọn giá trị rồi Enter.
  5. Các lệnh [!] dùng hộp xác nhận Y. Burn request dùng hộp CANCEL/FIRE riêng. q thoát DALTUI.
02 / THAO TÁC

HƯỚNG DẪN SỬ DỤNG DALTUI

DALTUI là giao diện terminal điều khiển OBC, EXP và PDU qua flight software. Các tab bên dưới tương ứng giao diện thật. Mỗi ô Status giải thích trạng thái được báo cáo; mỗi ô Control hướng dẫn thao tác theo thứ tự. Tên nút giữ tiếng Anh để đối chiếu trực tiếp. Chọn một khối Control để đánh dấu phần đang đọc.

MOTOR CONTROL

CONTROL · TRÌNH TỰ THAO TÁC
  1. Bật MOTOR rail → Detect DRV8910 → Initialize driver → Driver status.
  2. Chọn Motor. Khi motor dừng, nhập Max speed → Set max speed; Duty cycle → Set duty cycle; PWM frequency → Set PWM. Duty motor hiện giới hạn 1–80%.
  3. Chọn Mode → Set mode → Read mode. Nhập Direction, Speed và Move steps.
  4. MANUAL: Move CW/CCW chạy số bước tương đối; Jog chạy liên tục tới khi dừng. Chuyển động MANUAL không giám sát limit quang.
  5. OPERATION: hoàn tất MOTOR MAPPING trước, sau đó dùng Move with limits hoặc HOME. Khi chạm limit/HOME, firmware giữ pha tại điểm dừng.
  6. STOP MOTOR khi đang chạy sẽ dừng và giữ; nhấn lại khi đang giữ để nhả hold. Hoạt động motor mới thay đổi trạng thái giữ. STOP ALL dừng tất cả.
  7. Chọn Read settings để xác nhận cấu hình và trạng thái limit; xử lý nguyên nhân lỗi trước khi Clear faults.

PDU CONTROL

CONTROL · TRÌNH TỰ THAO TÁC
  1. Xác nhận PDU online, xem lỗi và điện áp hiện tại trước khi thay đổi nguồn.
  2. Chọn VOUT setpoint theo yêu cầu tải; đơn vị mV (800–20000 mV theo bảng điều khiển).
  3. Dùng VOUT enable hoặc TRANS branch cho nhánh cần dùng. VOUT ON cũng cấp TRANS; TRANS OFF kéo VOUT OFF.
  4. Nếu có lỗi, xem Faults; xử lý nguyên nhân trước Clear latched faults hoặc Immediate retry.
  5. Heartbeat enable và LED on/off period điều khiển đèn heartbeat khi dùng lệnh được FSW hỗ trợ.
  6. Các mục chưa được nối flight command sẽ hiện n/a/thông báo unavailable. Hiện Mode request, Immediate retry và Temperature limit chưa được expose qua DALTUI live.
  7. Enter bootloader là thao tác đặc biệt có xác nhận, làm PDU ngừng vận hành bình thường; không dùng trong quy trình bật nguồn thông thường.

CONFIGURATION

CONTROL · TRÌNH TỰ THAO TÁC
  1. Chọn Data source: Sim để mô phỏng, Console để dùng flight console cục bộ, RS-422 để gửi giao thức nhị phân.

  4. Xem Link status và Command history. Clear history xóa lịch sử giao dịch hiển thị.
  5. Dùng < / > hoặc p trong CFG để chuyển nhóm Flight software serial ports; mục này là section của CFG trong DALTUI.

FLIGHT SOFTWARE SERIAL PORTS

CONTROL · TRÌNH TỰ THAO TÁC
  1. Dùng kết nối Console cục bộ để sửa cấu hình cổng của FSW.
  2. Chọn Read settings và chờ tải cấu hình đã lưu trước khi sửa. Sau đó chọn cổng cần chỉnh → Enter → nhập đường dẫn/baud/địa chỉ → Enter để lưu. Đọc phản hồi xác nhận.
  3. Các giá trị được lưu qua FSW vào /etc/default/dal-obc-fsw và có hiệu lực khi FSW khởi động lại.
  4. Sau khi kiểm tra cấu hình đã lưu, chọn Restart FSW để áp dụng; hoặc chạy trên OBC: systemctl restart dal_obc_fsw. Kết nối hiện tại có thể gián đoạn; mở/reconnect DALTUI sau đó.
Mặc định từ code: Ground RS-422 = /dev/ttyS1; EXP UART CLI = /dev/ttyS4; EXP CSP RS-485 = /dev/ttyS2. Override trên máy chạy có thể thay đổi các giá trị này. PDU Modbus và EXP CSP RS-485 cần cổng riêng.
