Worked example 

dat_lst          -> 10 files total, snap_id=5
dat_mark on #3    -> tag it mark=7 (file "HK_...7.log")
dat_lst 7         -> NEW snap_id=6, hk[] now has ONLY that 1 file, index 0 = it
dat_sel 0 0 512   -> selects that file (index 0 of THIS filtered listing)
dat_lst           -> NEW snap_id=7, hk[] back to all 10 files, filtered listing is GONE
dat_sel 0 ...     -> now selects a DIFFERENT file (index 0 of the full list)
